# Makeup Data Analysis 💄📊

This project explores a personal makeup (lip products) inventory using Python and pandas.

## Goals
- Track makeup brands, products, and shades
- Analyze color families and undertones
- Identify which products align with a Soft / True Autumn palette
- Practice real-world data cleaning and analysis

## Data
- Initial data was manually collected and validated
- Stored as a CSV in the `data/` directory

## Tools
- Python
- pandas
- Jupyter Notebook
